# [[프로그래머스/LV2] 광물캐기 - backtracking (Java)](https://school.programmers.co.kr/learn/courses/30/lessons/172927)



## 🙋‍♂️ 들어가며

이 문제를 읽어보니 일단 제약사항에서 다음과 같은 특징을 알 수 있었다

### 제약사항
- 곡괭이중 아무거나 1개 선택
- 광물은 순서대로 캐는데, 5개 연속으로 캐야하고, 모든 광물을 캐거나, 더 사용할 곡괭이가 없을때까지 진행
	- dia기준 -> 전부 1소모
	- iron 기준 -> dia 5, 나머지 1소모
	- stone 기준 -> dia 25, iron 5, stone 1소모
- minerals 길이 50

<br><br>

### 아이디어
dia, iron, stone 곡괭이라는 3개의 선택지와 한 곡괭이를 고르면 연속 5개씩 캘 것

그리고 minerals 길이가 50이라 백트랙킹을 하면 최대깊이는 10까지이며, 

최악의 연산일 경우 (  3^0 + 3^1 + 3^2 + ... + 3^10 ) * 5  이라 백트랙킹으로 해결할 수 있을 것 같다

최악의 연산횟수를 확인하자
최대 재귀호출 횟수는 등비수열공식을 이용해서 빠르게 계산할 수 있다

S = a * (r^n - 1) / (r - 1) ==> (3^11 - 1) / (3 - 1) ==> 한 88000?

거기에 반복문 5회 곱해서 약 44만 정도?

<br>

### 코드 구조
```
1. 백트랙킹 (idx, 미네랄배열, 미네랄길이, 현재합, dia 삽 갯수, iron 삽 갯수, stone 삽 갯수)
	1-1. 만약 (끝점 도달했거나, dia, irone, stone 삽이 0이면 최소값 비교후 갱신)
	
	1-2. 위 경우가 아닐 때 (if 문 3개), 그리고 모든 조건문을 볼텐데, 각 백트랙킹에 영향이 없도록, 각 조건문마다 별도의 idx, 합 이라는 2개의 변수를 생성

	1-2-a.  if (dia 삽 > 0)
	1-2-b. if (iron 삽 > 0)
	1-2-c. if (stone 삽 > 0)

2. 답
```


<br><br>


## ✅ 코드 (backtracking)

```java
class Solution {
    static int answer;

    public int solution(int[] picks, String[] minerals) {
        answer = Integer.MAX_VALUE;

        // 1. 백트랙킹
        int idx = 0;
        int N = minerals.length;
        int cur_sum = 0;
        int dia = picks[0];
        int iron = picks[1];
        int stone = picks[2];
        back_tracking(idx, minerals, N, cur_sum, dia, iron, stone);

        // 3. 답 변환
        return answer;
    }




    // 2. 함수 (백트랙킹)
    static void back_tracking(int cur_idx, String[] minerals, int N, int cur_sum, int dia, int iron, int stone) {
        // 2-1. 만약 (끝점 도달했거나, dia, iron, stone 삽이 0이면 최소값 비교후 갱신)
        if (cur_idx == N || (dia == iron && iron == stone && stone == 0)) {
            answer = Math.min(cur_sum, answer);
            return;
        }


        // 2-2. 위 경우가 아닐때

        // 2-2-a. (dia 삽 > 0)
        if (dia > 0) {
            int new_idx = cur_idx;
            int new_sum = cur_sum;
            for (int i = 0; i < 5; i++) {
                if (new_idx == N) break;
                new_sum++;
                new_idx++;
            }
            back_tracking(new_idx, minerals, N, new_sum, dia-1, iron, stone);
        }

        // 2-2-b. (iron 삽 > 0) {
        if (iron > 0) {
            int new_idx = cur_idx;
            int new_sum = cur_sum;
            for (int i = 0; i < 5; i++) {
                if (new_idx == N) break;

                String cur_jewel = minerals[new_idx];
                if (cur_jewel.equals("diamond")) new_sum += 5;
                else if (!cur_jewel.equals("diamond")) new_sum++;
                new_idx++;
            }
            back_tracking(new_idx, minerals, N, new_sum, dia, iron-1, stone);
        }

        // 2-2-c. (stone 삽 > 0)
        if (stone > 0) {
            int new_sum = cur_sum;
            int new_idx = cur_idx;
            for (int i = 0; i < 5; i++) {
                if (new_idx == N) break;

                String cur_jewel = minerals[new_idx];
                if (cur_jewel.equals("diamond")) new_sum += 25;
                else if (cur_jewel.equals("iron")) new_sum += 5;
                else new_sum++;

                new_idx++;
            }
            back_tracking(new_idx, minerals, N, new_sum, dia, iron, stone-1);
        }



    }



}
```
