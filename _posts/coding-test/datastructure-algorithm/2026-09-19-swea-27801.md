# [[swea-D2] 27801. 변형된 카이사르 암호 해독](https://swexpertacademy.com/main/solvingProblem/solvingProblem.do)



## 🙋‍♂️ 문제 설명
카이사르 암호(Caesar cipher)는 시저 암호라고도 불리며,  
알파벳의 각 문자를 일정한 거리만큼 이동시켜 다른 문자로 바꾸는 암호 방식이다.

알파벳의 끝을 넘어가는 경우에는 다시 처음으로 돌아간다.

예를 들어 `Z`를 오른쪽으로 3칸 이동시키면 `C`가 된다.

---

## 암호 해독 규칙

일반적인 카이사르 암호에서는 모든 문자를 같은 거리만큼 이동하지만,  
이 문제에서는 **문자의 위치에 따라 이동하는 방향과 이동량이 달라진다.**

암호문의 첫 번째 문자부터 차례대로 다음 규칙을 적용한다.

1. 홀수 번째 문자는 알파벳 순서의 **오른쪽으로 해당 위치만큼** 이동한다.
2. 짝수 번째 문자는 알파벳 순서의 **왼쪽으로 해당 위치만큼** 이동한다.
3. `Z`에서 오른쪽으로 이동하면 다시 `A`부터 이어진다.
4. `A`에서 왼쪽으로 이동하면 다시 `Z`부터 이어진다.

즉, 각 위치에서의 이동 방향과 이동량은 다음과 같다.

| 위치 | 이동 |
|---:|---:|
| 1번째 | +1 |
| 2번째 | -2 |
| 3번째 | +3 |
| 4번째 | -4 |
| 5번째 | +5 |
| 6번째 | -6 |
| ... | ... |

여기서 `+`는 알파벳 순서의 오른쪽으로 이동하는 것을,  
`-`는 알파벳 순서의 왼쪽으로 이동하는 것을 의미한다.

---

## 예시

암호문 `XQRGVTPQE`가 주어졌다고 하자.

각 문자에 규칙을 적용하면 다음과 같다.

| 구분 | 1번째 | 2번째 | 3번째 | 4번째 | 5번째 | 6번째 | 7번째 | 8번째 | 9번째 |
|---|---|---|---|---|---|---|---|---|---|
| 암호문 | X | Q | R | G | V | T | P | Q | E |
| 이동 | +1 | -2 | +3 | -4 | +5 | -6 | +7 | -8 | +9 |
| 해독 결과 | Y | O | U | C | A | N | W | I | N |

따라서 암호문을 해독한 결과는

```text
YOUCANWIN
```

이 된다.

만약 `N = 3`이라면, 해독된 문자열을 앞에서부터 3글자씩 나누어 각 단어 사이에 하나의 공백을 추가한다.

```text
YOU / CAN / WIN
```

따라서 완성된 문장은 다음과 같다.

```text
YOU CAN WIN
```

## 문제

각 테스트 케이스에는 정수 `N`과 알파벳 대문자로 이루어진 암호문 `S`가 주어진다.

주어진 규칙에 따라 암호문 `S`를 해독하고,  
해독된 문자열을 앞에서부터 `N`글자씩 나누어 하나의 문장으로 만들어 출력하라.

나누어진 각 문자열 사이에는 하나의 공백을 추가한다.

---

## 입력

첫 번째 줄에 테스트 케이스의 수 `T`가 주어진다.

각 테스트 케이스는 두 줄로 구성된다.

- 첫 번째 줄에는 해독된 문자열을 몇 글자씩 나눌 것인지를 나타내는 정수 `N`이 주어진다.
- 두 번째 줄에는 알파벳 대문자로만 이루어진 암호문 `S`가 주어진다.

---

## 제약 사항

1. 암호문 `S`는 알파벳 대문자 `A`부터 `Z`까지만으로 이루어진다.
2. 문자열의 첫 번째 문자의 위치는 `1`이다.
3. 알파벳의 범위를 벗어나 이동하는 경우 `A`와 `Z`가 서로 이어져 있다고 생각한다.
4. `1 ≤ N ≤ |S|`
5. 해독된 문자열의 길이는 `N`의 배수이다.

---

## 출력

각 테스트 케이스마다 암호문을 주어진 규칙에 따라 해독한다.

해독된 문자열을 `N`글자씩 나누고, 나누어진 문자열 사이에 하나의 공백을 추가하여 완성된 문장을 출력한다.

각 테스트 케이스의 결과는 다음 형식으로 출력한다.

```text
#tc 정답
```

`tc`는 테스트 케이스의 번호이며 `1`부터 시작한다.

---

## 입력 예시

```text
4
3
XQRQVEGWKGXZOIEOXMJUSPUW
4
XQRVOOFMNSAXPCXUBLHSHWOK
5
UCIYZZKCKRPNBJPFAAKY
6
KKQXGKMPZXVEPFPQCWJBFJJC
```

---

## 출력 예시

```text
#1 YOU MAY NOT WIN BUT YOU CAN TRY
#2 YOUR TIME WILL COME STAY CALM
#3 VALUE TRUTH ABOVE PRIDE
#4 LITTLE THINGS CREATE CHANGE
```

## ✅ 정답 코드
```java
import java.io.IOException;
import java.io.BufferedReader;
import java.io.InputStreamReader;


public class Solution {
	public static void main(String[] args) throws IOException {
		BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
		int T = Integer.parseInt(br.readLine());
		for (int tc = 1; tc < T+1; tc++) {
			int space_cnt = Integer.parseInt(br.readLine());
			String S = br.readLine();
			
			// space_cnt 만큼 채우면 공백 추가하고 다시 cnt = 0으로 갱신, i < N-1 미만일때만 유효
			int cnt = 0;
			StringBuilder sb = new StringBuilder();
			
			// 암호문S의 길이는 26
			for (int i = 0; i < S.length(); i++) {
				char cur_ch = S.charAt(i);
				int step = i+1;
				
				// 기본적으로 step은 양수처리니 홀수 idx일때만 처리하면 된다.
				if (i % 2 == 1) step -= 2*step;
				
				// 새로운 idx
				int idx = (cur_ch - 'A' + 26 + step) % 26;
				
				// 새로운 글자
				char new_ch = (char) (idx + 'A');
				sb.append(new_ch);
				cnt++;
				
				// space_cnt 개씩 나누고, idx가 맨마지막 미만일때만
				if (cnt == space_cnt && i <= S.length()-2) {
					sb.append(" ");
					cnt = 0;
				}
			}
			// 출력
			System.out.println("#" + tc + " " + sb.toString());
			
		}
	}
}
```
