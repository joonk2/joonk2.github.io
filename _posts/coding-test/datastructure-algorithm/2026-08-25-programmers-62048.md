규칙을 통해 이런 형식을 구할 수 있었다

```java
 ( (long) (w*h) ) - (w + h) - gcd(w,h)
```

이는 `유클리드 호제법`을 통해 최대공약수를 구하는 방법으로 예시는 다음과 같다

## ✅ 정답 코드
```java
class Solution {
    public long solution(int w, int h) {
        long answer = 1;
        long my_gcd = gcd(w, h);
        long to_minus = ( (long) w+h ) - my_gcd;
        answer = ( (long) w*h ) - to_minus;
        
        return answer;
    }
    
    
    static long gcd(int w, int h) {
        long a = Math.max(w, h);
        long b = Math.min(w, h);
        long res = 0;
        
        while (b != 0) {
            long remainder = (long) (a % b);
            a = b;
            b = remainder;
        }
        res = a;
        return res;
    }
    
    
}
```
