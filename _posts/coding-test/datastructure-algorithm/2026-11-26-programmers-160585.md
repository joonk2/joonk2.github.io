# [[프로그래머스/LV2] 혼자서 하는 틱택토 - implementation, backtracking (Java)](https://school.programmers.co.kr/learn/courses/30/lessons/160585)



## 🙋‍♂️ 들어가며

이 문제를 읽어보니 일단 제약사항에서 다음과 같은 특징을 알 수 있었다

### 제약사항
- 선공은 O, 후공은 X
- 배열은 3*3

<br>

### 아이디어
테스트 케이스를 보면 아래와 같은 경우는 성립할 수 없어서 0을 반환한다고 한다.
```
O O O
. . .
X X X
```

그렇다면, 우리가 아래 배열을 정답배열이라 생각하고 또 그 전에 빙고가 나올 수 있는 경우들을 생각해보자
```
O . X
O O .
X X O
``` 

5개부터 O빙고가 나올 수 있겠더라
```
O . .
. O .
X X O
```
혹은 6개일 때 X도 빙고 가능, 근데 생각해보면 6개일때 O도 빙고가 가능하다
```
O . X
. X .
X O O
```
하지만 5개부터 첫 빙고가 나올 수 있으므로, 이에 5개 이상의 돌을 배치했을때, O 혹은 X 둘중 하나라도 빙고일때, 만약 정답과 다르다면 그때부터는 무의미하기에 볼 필요가 없다.
참 그리고 O가 선공이기에 O, X 합쳐서 홀수일때는 O가 무조건 1개 더 많아야하는데 X가 많으면 그건 잘못된 것으로 조기종료를 할 수 있었다.
그래서 조기종료를 위의 2경우로 배치할 수 있을 것 같았다.

저 특징들을 보니 `빡구현 + 백트랙킹`이 생각나는데, 실제로 코드로 가능할지 제약조건을 봤으나, 막상 시간복잡도 계산하기 위해 최악의 테스트케이스를 보자
```
O X O
O X X
X O O
```
N = 9, O = 5, X = 4 이다

알기쉽게 코드 일부를 준비해보았다.

```java
static void back_tracking(...) {

    if (found) return;

    if (idx == N) {
        // 끝점 좌표 비교
        // 최대 5 * 5 + 4 * 4 = 41회
        return;
    }

    // 1. 빙고 검사
    // 최대 8 * 3 * 8 = 192회
    if (idx >= 5 && is_one_of_them_bingo(my_o, my_x)) {
        return;
    }

    // 2. 돌 배치
    // 최대 3 * 3 = 9회
    for (int r = 0; r < 3; r++) {
        for (int c = 0; c < 3; c++) {
            // 조건 검사
            // 재귀 호출
        }
    }
}
```

최대 재귀호출횟수, O= 5, X = 4 일때까지 이렇게 계산할 수 있다
- idx = 0 : 최초 호출          1회
- idx = 1 : O 5개 중 선택      1 * 5 = 5회
- idx = 2 : X 4개 중 선택 (O는 이미 1개 선택됨)      5 * 4 = 20회
- idx = 3 : O 4개 중 선택 (O 1개, X는 이미 1개 선택됨)     20 * 4 = 80회
- idx = 4 : X 3개 중 선택  (O 2개, X는 이미 1개 선택됨)    80 * 3 = 240회
- idx = 5 : O 3개 중 선택  (이하동문)  240 * 3 = 720회
- idx = 6 : X 2개 중 선택  (이하동문)  720 * 2 = 1440회
- idx = 7 : O 2개 중 선택 (이하동문)  1440 * 2 = 2880회
- idx = 8 : X 1개 중 선택 (이하동문)  2880 * 1 = 2880회
- idx = 9 : O 1개 중 선택 (이하동문)  2880 * 1 = 2880회


<br>

최악의 수행 연산횟수는 다음과 같다
(11146 - 2880) * (192 + 9) + 2880 * (5*5 + 4*4)

idx = 0 ~ 8까지 더한게 11146 - 2880
192 + 9 -> 빙고검사 + 돌배치
2880 * (5*5 + 4*4) -> idx : 9일때, 최대깊이니까 검사

약 178만회로 충분히 통과가능.

<br><br>


### 코드 구조
1. 빙고용 확인 틀 8개
2. main
	2-1. 내 틱택토O, 틱택토X의 HashSet에 각각 좌표 추가
	2-2. 조기검사
	2-3. 백트랙킹
	2-4. 답

3. 함수 (백트랙킹)
	3-1. 답 찾았으면 -> 끝
	3-2. 끝점 도달시 -> 내가 찾은 O, X 좌표들과 정답 O, X 좌표들 맞나 검사 -> 맞으면 true -> 그리고 종료
	3-3. 만약 (5개 이상 && 끝점 도달전에 빙고 발생시, 해당 분기만 종료)
	3-4. 위 경우가 아니라면 (선O, 후X)
	만약, 나머지가 짝수일 때, O -> 백트랙킹
	그렇지않고, 나머지가 홀수일 때, X -> 백트랙킹
	여기서 최적화도 가능 (빈칸이 아니고, 정답배열의 좌표와 다르면 skip)

4. 함수 (내 좌표는 빙고인가?)
	4-1. O가 빙고인지 확인
	4-2. X가 빙고인지 확인
	4-3. 만약, 둘중 하나 빙고면 -> true
	4-4. 그외, -> false 

<br><br>


## ✅ 코드 (implementation + backtracking)

```java
import java.util.Set;
import java.util.HashSet;



class Solution {
    static boolean found = false;

    static Set<int[]> res_o = new HashSet<>();
    static Set<int[]> res_x = new HashSet<>();

    static int[][][] check = {
        // ㅡ
        { {0,0}, {0,1}, {0,2} },
        { {1,0}, {1,1}, {1,2} },
        { {2,0}, {2,1}, {2,2} },

        // |
        { {0,0}, {1,0}, {2,0} },
        { {0,1}, {1,1}, {2,1} },
        { {0,2}, {1,2}, {2,2} },

        // \
        { {0,0}, {1,1}, {2,2} },

        // /
        { {0,2}, {1,1}, {2,0} },
    };


    public int solution(String[] board) {
        int answer = 0;
        int N = 0;

        char[][] res_arr = new char[3][3];
        for (int r = 0; r < 3; r++) {
            String cols = board[r];
            for (int c = 0; c < 3; c++) {
                res_arr[r][c] = cols.charAt(c);
                char cur = res_arr[r][c];
                if (cur == 'O') {
                    res_o.add(new int[] {r, c});
                    N++;
                }
                else if (cur == 'X') {
                    res_x.add(new int[] {r, c});
                    N++;
                }
            }
        }

        // 1. 내 틱택토 저장할 공간
        Set<int[]> my_o = new HashSet<>();
        Set<int[]> my_x = new HashSet<>();
        char[][] my_arr = new char[3][3];  
        for (int r = 0; r < 3; r++) {
            for (int c = 0; c < 3; c++) {
                my_arr[r][c] = '.';
            }
        }       

        // 2. 조기 검사
        int sum_o = 0;
        int sum_x = 0;
        if (N % 2 == 0) {
            int mod = N / 2;
            sum_o += mod;
            sum_x += mod;
        }
        else if (N % 2 == 1) {
            int mod = N / 2;
            sum_o += mod;
            sum_x += mod;
            sum_o++;
        }

        if (sum_o != res_o.size() && sum_x != res_x.size()) {
            return 0;
        }



        // 3. 백트랙킹
        int idx = 0;
        back_tracking(idx, N, my_arr, my_o, my_x, res_arr);

        // 6. 답
        if (!found) answer = 0;
        else answer = 1;
        return answer;
    }



    // 4. 함수 (백트랙킹)
    static void back_tracking(int idx, int N, char[][] my_arr, Set<int[]> my_o, Set<int[]> my_x, char[][] res_arr) {

        // 4-1. 답 찾았으면 끝
        if (found) return;

        // 4-2. 끝점 도달시
        if (idx == N) {
            int cnt_o = 0;
            int cnt_x = 0;
            int total_o = res_o.size();
            int total_x = res_x.size();
            for (int[] i : my_o) {
                for (int[] j : res_o) {
                    if (i[0] == j[0] && i[1] == j[1]) cnt_o++;
                }
            }
            for (int[] i : my_x) {
                for (int[] j : res_x) {
                    if (i[0] == j[0] && i[1] == j[1]) cnt_x++;
                }
            }


            if (cnt_o == total_o && cnt_x == total_x)  {
                found = true;
            }
            return;
        }



        // 4-3. 만약 (5개 이상 && 끝점 도달전에 빙고 발생시, 해당 분기만 종료)
        if (idx >= 5 && is_one_of_them_bingo(my_o, my_x)) {
            return;
        }




        // 4-4. 위 경우가 아니라면 (선O, 후X)
        if (idx % 2 == 0) {
            for (int r = 0; r < 3; r++) {
                for (int c = 0; c < 3; c++) {

                    // 4-4-a. 최적화 (빈칸이 안비었고, 결과배열과 다르면 pass -> 백트랙킹 안함)
                    if (my_arr[r][c] != '.' || res_arr[r][c] != 'O') continue;
                    my_arr[r][c] = 'O';
                    int[] pos = new int[] {r, c};
                    my_o.add(pos);
                    back_tracking(idx + 1, N, my_arr, my_o, my_x, res_arr);
                    my_arr[r][c] = '.';          
                    my_o.remove(pos);
                }
            }
        }
        else if (idx % 2 == 1) {
            for (int r = 0; r < 3; r++) {
                for (int c = 0; c < 3; c++) {
                    // 4-4-b. 최적화 (빈칸이 안비었고, 결과배열과 다르면 pass -> 백트랙킹 안함)
                    if (my_arr[r][c] != '.' || res_arr[r][c] != 'X') continue;
                    my_arr[r][c] = 'X';
                    int[] pos = new int[] {r, c};
                    my_x.add(pos);
                    back_tracking(idx + 1, N, my_arr, my_o, my_x, res_arr);
                    my_arr[r][c] = '.';          
                    my_x.remove(pos);
                }
            }
        }


    }


    // 5. 함수 (내 o,x중 하나는 빙고인가?)
    static boolean is_one_of_them_bingo(Set<int[]> my_o, Set<int[]> my_x) {
        boolean is_o_bingo = false;
        boolean is_x_bingo = false;

        // 5-1. 내 o 확인
        int M = check.length;
        int total_cnt = 3;
        for (int i = 0; i < M; i++) {
            int cnt = 0;
            for (int j = 0; j < 3; j ++) {
                int[] cur_pos = check[i][j];
                int cur_r = cur_pos[0];
                int cur_c = cur_pos[1];
                for (int[] k : my_o) {
                    int temp_r = k[0];
                    int temp_c = k[1];
                    if (cur_r == temp_r && cur_c == temp_c) {
                        cnt++;
                        break;
                    }
                }
            }
            if (cnt == 3) {
                is_o_bingo = true;
                break;
            }
        }




        // 5-2. 내 x 확인
        for (int i = 0; i < M; i++) {
            int cnt = 0;
            for (int j = 0; j < 3; j ++) {
                int[] cur_pos = check[i][j];
                int cur_r = cur_pos[0];
                int cur_c = cur_pos[1];
                for (int[] k : my_x) {
                    int temp_r = k[0];
                    int temp_c = k[1];
                    if (cur_r == temp_r && cur_c == temp_c) {
                        cnt++;
                        break;
                    }
                }
            }
            if (cnt == 3) {
                is_x_bingo = true;
                break;
            }
        }


        // 5-3. 둘중 하나라도 빙고면 
        if (is_o_bingo || is_x_bingo) return true;

        return false; 
    }

}
```
